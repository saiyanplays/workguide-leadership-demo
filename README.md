# WorkGuide Leadership Website Demo

Demo-only static website. Do not add Ericsson confidential, internal operational, personal, or production information to a public GitHub Pages deployment.

## Publish using GitHub Pages
1. Create a new GitHub repository, for example `workguide-leadership-demo`.
2. Upload ALL contents of this ZIP to the repository root, including `.github`.
3. Commit to `main`.
4. In GitHub open Settings > Pages.
5. Under Build and deployment, choose **GitHub Actions** as the Source if it is not already selected.
6. Open Actions and let **Deploy WorkGuide Leadership Demo** finish.
7. GitHub will show the website URL in the deployment.

If the repository/account cannot provide a privately published GitHub Pages site, assume the demo URL is public. Keep demo data synthetic.
